# 1. Objetivo

Definir los indicadores oficiales utilizados por LogiMind Logistics S.A.S. para medir el desempeño de los procesos logísticos, apoyar la toma de decisiones y evaluar el cumplimiento de los objetivos estratégicos de la organización.

---

# 2. Alcance

Este manual aplica a todos los procesos logísticos de la empresa y constituye la única referencia oficial para la definición, cálculo e interpretación de los indicadores de desempeño.

# 4. Indicadores Oficiales

## KPI-001 — OTIF (On Time In Full)

| Campo | Valor |
|--------|-------|
| Objetivo | Medir el porcentaje de pedidos entregados completos y a tiempo. |
| Fórmula | (Pedidos OTIF / Total de pedidos) × 100 |
| Unidad | % |
| Frecuencia | Mensual |
| Responsable | Coordinador de Transporte |
| Meta | ≥ 97 % |

---

## KPI-002 — Fill Rate

| Campo | Valor |
|--------|-------|
| Objetivo | Medir el porcentaje de la demanda atendida. |
| Fórmula | (Unidades entregadas / Unidades solicitadas) × 100 |
| Unidad | % |
| Frecuencia | Mensual |
| Responsable | Coordinador de Inventarios |
| Meta | ≥ 97 % |

---

## KPI-003 — Rotación de Inventario

| Campo | Valor |
|--------|-------|
| Objetivo | Evaluar la velocidad de renovación del inventario. |
| Fórmula | Consumo del período / Inventario promedio |
| Unidad | Veces |
| Frecuencia | Mensual |
| Responsable | Coordinador de Inventarios |
| Meta | Según categoría ABC |

---

## KPI-004 — Exactitud de Inventario

| Campo | Valor |
|--------|-------|
| Objetivo | Medir la concordancia entre el inventario físico y el registrado en el WMS. |
| Fórmula | (Registros correctos / Total de registros) × 100 |
| Unidad | % |
| Frecuencia | Mensual |
| Responsable | Supervisor de Bodega |
| Meta | ≥ 99 % |

---

## KPI-005 — Tiempo de Ciclo del Pedido

| Campo | Valor |
|--------|-------|
| Objetivo | Medir el tiempo transcurrido desde la recepción del pedido hasta su entrega. |
| Fórmula | Fecha de entrega − Fecha de recepción del pedido |
| Unidad | Horas |
| Frecuencia | Mensual |
| Responsable | Coordinador de Operaciones |
| Meta | ≤ Lead Time establecido |

---

## KPI-006 — Utilización de Flota

| Campo | Valor |
|--------|-------|
| Objetivo | Medir el nivel de utilización de los vehículos disponibles. |
| Fórmula | (Vehículos utilizados / Vehículos disponibles) × 100 |
| Unidad | % |
| Frecuencia | Mensual |
| Responsable | Coordinador de Transporte |
| Meta | ≥ 85 % |

---

## KPI-007 — Costo Logístico

| Campo | Valor |
|--------|-------|
| Objetivo | Medir el costo total de la operación logística. |
| Fórmula | Costos logísticos / Ventas |
| Unidad | % |
| Frecuencia | Mensual |
| Responsable | Dirección de Operaciones |
| Meta | Según presupuesto anual |

---

## KPI-008 — Nivel de Servicio

| Campo | Valor |
|--------|-------|
| Objetivo | Medir el cumplimiento del servicio comprometido con los clientes. |
| Fórmula | (Pedidos atendidos correctamente / Total de pedidos) × 100 |
| Unidad | % |
| Frecuencia | Mensual |
| Responsable | Dirección de Operaciones |
| Meta | ≥ 97 % |

---

# 5. Lineamientos de Medición

Los indicadores deberán cumplir los siguientes lineamientos:

- Utilizar información proveniente del ERP, WMS y TMS.
- Medirse con la frecuencia establecida.
- Ser revisados por el responsable asignado.
- Utilizar una única definición corporativa.
- Mantener la trazabilidad de la información utilizada en su cálculo.
