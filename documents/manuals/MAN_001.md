# 4. Modelo Operativo

La operación logística de LogiMind Logistics se basa en la integración de procesos de abastecimiento, almacenamiento, administración de inventarios y distribución nacional, garantizando la trazabilidad de la mercancía durante todo su ciclo operativo.

Los procesos son soportados por sistemas ERP, WMS y TMS, permitiendo la gestión centralizada de pedidos, inventarios, transporte e indicadores de desempeño.

# 6. Macroprocesos Operativos

| Macroproceso | Objetivo |
|---------------|----------|
| Compras | Garantizar el abastecimiento oportuno de bienes y servicios. |
| Recepción | Verificar y registrar la mercancía recibida. |
| Almacenamiento | Ubicar la mercancía de forma segura y trazable. |
| Gestión de Inventarios | Controlar existencias y disponibilidad de productos. |
| Picking | Preparar los pedidos solicitados por los clientes. |
| Packing | Empacar y acondicionar los pedidos para despacho. |
| Despacho | Liberar los pedidos para distribución. |
| Transporte | Distribuir la mercancía según la planeación logística. |
| Entrega | Completar la entrega al cliente y registrar la evidencia correspondiente. |

# 7. Roles y Responsabilidades

| Cargo | Responsabilidad Principal |
|--------|---------------------------|
| Director de Operaciones | Dirigir la operación logística nacional. |
| Coordinador de Compras | Gestionar el abastecimiento y proveedores. |
| Coordinador de Inventarios | Administrar los niveles de inventario. |
| Coordinador de Transporte | Planificar y supervisar la distribución. |
| Coordinador de Calidad | Verificar el cumplimiento del Sistema de Gestión de Calidad. |
| Supervisor de Bodega | Coordinar las operaciones del centro de distribución. |
| Analista Logístico | Monitorear indicadores y apoyar la toma de decisiones. |
| Auxiliar Logístico | Ejecutar actividades operativas. |
| Conductor | Ejecutar las rutas de distribución asignadas. |

# 8. Sistemas de Información

La operación logística utiliza los siguientes sistemas corporativos:

| Sistema | Función |
|----------|---------|
| ERP | Gestión administrativa y financiera. |
| WMS | Administración de almacenes e inventarios. |
| TMS | Planeación y seguimiento del transporte. |
| Plataforma BI | Visualización de indicadores y análisis operativo. |

# 9. Indicadores Estratégicos

La operación es monitoreada mediante los siguientes indicadores corporativos:

- OTIF.
- Fill Rate.
- Exactitud de Inventario.
- Rotación de Inventario.
- Tiempo de Ciclo del Pedido.
- Productividad de Picking.
- Productividad de Packing.
- Utilización de Flota.
- Nivel de Servicio.
- Costo Logístico.

Las definiciones, fórmulas y metas oficiales se encuentran en **KPI-001 – Manual de Indicadores Logísticos**.
